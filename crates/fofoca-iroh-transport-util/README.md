# fofoca-iroh-transport-util

Path selection and GSO unbatching shared by the two fofoca iroh custom
transports (`fofoca-iroh-webrtc-transport` and
`fofoca-iroh-multihop-transport`).

A small crate with no network code of its own. See `src/lib.rs` for the
API and for why it is a crate rather than a module.
